Streaming file encryption CLI written in Rust using authenticated AES-256-GCM with Argon2id password-based key derivation. Encrypts and decrypts files chunk-by-chunk in 64 KiB blocks so multi-gigabyte files never load into memory. Live progress bar, batch mode over an entire directory, atomic file header with magic bytes and version, per-chunk random 96-bit nonce, per-file random 128-bit salt, in-memory zeroization of derived keys via zeroize, hidden password prompts via rpassword. Cross-platform (Linux, macOS, Windows).
